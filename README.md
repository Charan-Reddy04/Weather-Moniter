# 🌤️ Weather Moniter

A simple and user-friendly **Weather Monitoring Web Application** that allows users to check current weather information for different locations.

## 🚀 Features

* 🌍 Search weather by city name
* 🌡️ Display current temperature
* 💧 Show humidity information
* 💨 Display wind speed
* ☁️ Show weather conditions
* 🔎 Simple and responsive user interface
* 📱 Works across different screen sizes

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive design
* **JavaScript** – Application logic and API handling
* **Weather API** – Fetching real-time weather information

## ⚙️ How It Works

1. Enter a city name in the search box.
2. Click the search button.
3. The application sends a request to the weather API.
4. The API returns the weather information.
5. The application displays the weather details on the screen.

## ▶️ How to Run
